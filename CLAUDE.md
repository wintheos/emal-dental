# Эмаль — лендинг стоматологической клиники

Учебный проект для портфолио. Статичный сайт без сборки: один `index.html` со встроенными стилями и скриптом, картинки в `images/`. Публикуется через GitHub Pages из ветки `main`.

## Где что лежит

- `index.html` — вся страница. Цвета, отступы и радиусы заданы CSS-переменными в `:root` в начале `<style>`.
- `tokens.css` — те же токены дизайн-системы отдельным файлом (для новых страниц).
- `docs/design-system.md` — правила дизайн-системы: палитра, типографика, голос, компоненты.
- `docs/tokens.json` — исходные токены.
- `docs/brief.md` — бриф, ключевое сообщение и структура лендинга по блокам.
- `images/` — фото (hero-*, svc-* для услуг, doc-* для врачей), сжатые JPEG до ~2000 px.

## Правила

- Используй только токены: никаких новых hex-цветов в компонентах. Тёмная тема переопределяет те же токены.
- Шрифт — Onest (Google Fonts), начертания 400/500/600.
- Одна основная кнопка `btn-primary` на экран — «Записаться». Остальные — `btn-secondary` / ghost.
- Текст — только `--ink` и `--ink-muted`; `--sand-500` и `--brand-500` не для мелкого текста.
- Красный (`--danger`) — только для ошибок.
- Тон текстов: спокойно, на «вы», конкретные цифры, без восклицательных знаков.
- Проверяй вёрстку на ширине 360–390 px: без горизонтального скролла.
- Клиника, врачи, цены и адрес вымышлены — сохраняй строку об этом в футере.
