# Эмаль — стоматологическая клиника

Лендинг вымышленной стоматологической клиники «Эмаль»: имплантация и эстетика с цифровым планом лечения. Учебный проект для портфолио.

**Сайт:** https://wintheos.github.io/emal-dental/

## Что внутри

- Дизайн-система: глубокий петроль как цвет доверия, тёплый песочный акцент, шрифт Onest, светлая и тёмная темы — [docs/design-system.md](docs/design-system.md).
- Бриф и структура лендинга из 12 блоков — [docs/brief.md](docs/brief.md).
- Первый экран со слайдером фото, пример плана лечения с зубной формулой, карточки услуг и врачей, интерактивная форма записи с выбором дня и времени.
- Адаптивная вёрстка: на телефоне закреплённая панель записи.

## Запуск

Сборка не нужна — откройте `index.html` в браузере.

Клиника, врачи, цены и адрес вымышлены. Изображения сгенерированы ИИ.
